# MOVE UP FITNESS — ポートフォリオ用LP

## ファイル
- `index.html`：ページ構造と日本語コンテンツ
- `style.css`：レスポンシブ対応デザイン
- `script.js`：スマホメニュー、FAQ、体験フォームのデモ動作
- `assets/hero-japanese-gym.jpg`：ヒーロー用画像
- `assets/program-*.jpg`：トレーニング紹介用画像
- `assets/facility-*.jpg`：施設紹介用画像
- 画像は日本人の若者が登場する生成デザイン参考画像から切り出したサンプルです

## 表示方法
1. ZIPを展開します。
2. `index.html` をChromeなどのブラウザで開きます。
3. Google Fontsは外部読み込みです。ローカル画像はZIP内に含まれています。

## 実装メモ
- スマートフォン・タブレット・デスクトップに対応
- ナビゲーション、FAQアコーディオン、体験申込フォームのデモを実装
- フォームは画面内の確認メッセージのみで、予約情報は送信・保存しません
- 料金・キャンペーン・口コミはポートフォリオ用の架空設定です
- 公開前に画像のライセンス、料金、店舗情報、フォーム送信先を確認してください
